Una Request è una richiesta pianificata che NON deriva da malfunzionamento, ma da esigenza operativa, informativa o di miglioramento.

CRITERI DI CLASSIFICAZIONE:

1. ACCESSO E ABILITAZIONE

Creazione/Modifica Utenze:
- Richiesta creazione utenza, nuovo utente
- Attivazione/abilitazione account
- Modifica permessi, cambio ruolo
- Disabilitazione utente, rimozione accesso
- Reset password (richiesto dall'utente)

Accesso Servizi/Applicazioni:
- Richiesta accesso a [applicazione]
- Abilitazione servizio, attivazione modulo
- Concessione licenza
- Integrazione con [sistema esterno]

2. INFORMAZIONE E SUPPORTO

Richieste Informative:
- Richiesta informazioni, chiarimenti
- Come posso..., è possibile...
- Vorrei sapere..., delucidazioni
- Conferma procedura, validazione operazione
- Richiesta documentazione/manuale

Supporto Operativo (NON malfunzionamento):
- Supporto/assistenza per...
- Aiuto nell'esecuzione, guida
- Affiancamento operativo, formazione
- Verifica correttezza dati inseriti

DISTINZIONE CRITICA:
- "Il sistema non mi permette di..." = INCIDENT
- "Non so come..." / "Vorrei essere guidato..." = REQUEST

3. MODIFICHE STANDARD

Modifiche Dati:
- Modifica anagrafica, aggiornamento dati
- Correzione dati inseriti (se ammessa)
- Rettifica informazioni (entro termini)
- Aggiornamento recapiti
- Modifica configurazione standard

Operazioni Pre-Approvate:
- Annullamento [entità] (su richiesta motivata)
- Cancellazione [record] (autorizzata)
- Riallineamento dati (pianificato)
- Migrazione dati (programmata)

4. MIGLIORAMENTO E NUOVE FUNZIONALITÀ

Enhancement:
- Sarebbe utile se..., sarebbe possibile implementare...
- Richiesta di miglioramento, suggerimento
- Ottimizzazione, semplificazione
- Rendere più efficiente, velocizzare
- Aggiungere campo, inserire funzione

Nuove Funzionalità:
- Feature request
- Sviluppo/creazione di...
- Implementazione modulo, nuovo servizio
- Dashboard personalizzata, report custom

5. AZIONI PIANIFICATE

Manutenzioni Programmate:
- Richiesta manutenzione preventiva
- Schedulazione intervento
- Backup programmato, archiviazione dati
- Pulizia database, ottimizzazione indici
- Aggiornamento versione (concordato)

Operazioni Massive:
- Elaborazione massiva, caricamento bulk
- Import/export pianificato
- Bonifica dati (programmata)
- Ricalcolo batch (schedulato)
- Generazione massiva documenti
