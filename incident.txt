Un Incident è un evento non pianificato che causa interruzione o riduzione della qualità di un servizio IT.

CRITERI DI CLASSIFICAZIONE:

1. INTERRUZIONE NON PIANIFICATA

Servizio Non Disponibile:
- Impossibile accedere/raggiungere [sistema]
- Servizio non risponde, timeout, connessione scaduta
- Sistema down, pagina bianca, errore di caricamento
- Si blocca al login
- Errori HTTP: 500, 502, 503, 504
- Connection refused/timeout, Service unavailable

Funzionalità Non Disponibile:
- Impossibile [azione specifica]
- Non permette di [operazione]
- Bloccato durante [fase]
- Funzione non disponibile

2. ERRORI DI SISTEMA

Codici Errore Applicativi:
- Formato: [numero]-[codice] (es: 1203-14br, 1201-3XDK)
- "Errore [codice]", "Exception [codice]"
- "Si è verificato un errore durante..."

Errori Database:
- Violation of PRIMARY KEY constraint
- Cannot insert duplicate key
- Foreign key constraint, Deadlock detected
- Transaction timeout, Database connection failed

Errori Frontend:
- DataTables warning
- Unexpected end of JSON input
- Object object
- The given key was not present in the dictionary
- Campi vuoti quando dovrebbero contenere dati

3. DEGRADO PRESTAZIONI

Lentezza Anomala:
- Sistema lento/lentissimo
- Risponde dopo molto tempo (>15 minuti senza risposta)
- Non finisce di caricare
- Ricerca/elaborazione infinita

Timeout:
- Timeout, Request timeout, Gateway timeout
- Sessione scaduta durante operazione

4. MALFUNZIONAMENTI

Dati Errati/Inconsistenti:
- Dati non corrispondono, differenza tra [A] e [B]
- Importo errato, valore sbagliato
- Discrepanza, scostamento
- Risulta [X] invece di [Y]
- Duplicazione non prevista

Stato Workflow Incoerente:
- Stato del decreto non consente [operazione]
- Risulta in stato [X] ma dovrebbe essere [Y]
- Stato incoerente, bloccato in stato [X]

Funzionalità Opera Male:
- Dovrebbe [atteso] ma [reale]
- Comportamento anomalo
- Salva valore diverso da inserito
- Non visualizza dati che dovrebbero esserci

5. PROBLEMI INTEGRAZIONE

Sistemi Esterni:
- Errore integrazione con [sistema esterno]
- PagoPA non risponde
- Firma digitale non funziona
- Workflow non aggiorna stato

Sincronizzazione:
- Dati non aggiornati
- Non sincronizzato con [sistema]
- Stato non allineato tra [A] e [B]

6. IMPATTO

Generalizzato (Critico):
- Il problema è generale
- Tutto l'ufficio/servizio
- Nessuno riesce

Singolo Utente (Medio):
- Solo io ho il problema
- I colleghi riescono
